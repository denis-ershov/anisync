# **App Name**: AniSync

## Core Features:

- User Authentication: Authenticate users via Shikimori OAuth.
- Anime List Retrieval: Fetch currently watching anime list from Shikimori.
- Anime List Display: Display anime list in a user-friendly format.
- List Filtering and Sorting: Filter and sort anime by title, status, or rating.
- Detailed Anime View: Detailed view with anime information (synopsis, cover, rating).
- AI Recommendations: Generate a recommendation, by analyzing data from the Shikimori site and the user's viewing history, and filtering down to anime not on the user's watch list. This feature acts as a tool which uses information available to the AI to suggest good anime.

## Style Guidelines:

- Dark Blue: #12232E
- Lighter Blue: #007CC7
- Lightest Blue: #4DA8DA
- Shadow of Dark Blue: #203647
- Shadow of Light Blue: #EEFBFB
- Font: 'Sofia Sans', sans-serif, for a modern and neutral look suitable for the main content.
- Use minimalist and consistent icons related to anime genres and status.
- Clean, card-based layout for anime entries to ensure easy scanning and interaction.
