# AniSync

**[anisync.ru](https://anisync.ru)** — личный хаб для аниме и релизов: одна учётная запись, три связанных модуля, настройка под себя в веб-интерфейсе.

Репозиторий описывает продукт. Запуск и использование — через сайт: регистрация, подключение сервисов и персональные настройки в аккаунте.

---

## Зачем это нужно

Вместо разрозненных вкладок Shikimori, календаря релизов и трекеров раздач — единое место:

- библиотека аниме с синхронизацией статусов;
- watchlist кино и сериалов с расписанием выхода;
- автоматический поиск подходящих раздач и уведомления.

Всё работает в браузере (и как PWA), на русском и английском.

---

## Модули

### Anime

Библиотека пользователя и синхронизация с внешними каталогами:

- **Shikimori**, **MyAnimeList**, **AniList** — OAuth и двусторонняя синхронизация статусов / прогресса;
- единый каталог тайтлов и персональная библиотека;
- фоновые задачи импорта и обновления записей, без «зависания» интерфейса.

### Releases

Календарь и список ожидания по данным **TMDB**:

- upcoming / trending / поиск;
- персональный watchlist;
- фоновое обновление дат выхода и карточек;
- удобный просмотр списком или сеткой, сортировка и пагинация.

### Torrents

Автопоиск раздач по вашему списку интереса:

- поиск через **Prowlarr**;
- фильтры качества, озвучки, сезона / эпизода;
- закрепление (pin), режим hunting, принятие (adopt) найденных релизов;
- уведомления **в приложении** и в **Telegram**.

Модули можно включать и выключать в настройках аккаунта — интерфейс подстраивается под то, чем вы реально пользуетесь.

## Возможности платформы

| Возможность | Описание |
|-------------|----------|
| Аккаунт и сессии | Регистрация, вход, настройки профиля и безопасности |
| Интеграции | Подключение Shikimori / MAL / AniList, Telegram, параметры поиска раздач |
| Уведомления | Единый центр: in-app + Telegram |
| Локализация | Русский и английский |
| PWA | Установка на устройство, работа при слабой сети |
| Адаптивный UI | Удобно на десктопе и мобильных |

Тяжёлая работа (синхронизация библиотеки, обновление watchlist, скан раздач) уходит в фоновые очереди — сайт остаётся отзывчивым.

## Стек

| Слой | Технологии |
|------|------------|
| Приложение | Next.js 15, React 19, TypeScript |
| Данные | PostgreSQL 18, Drizzle ORM |
| Очереди и кэш | Redis, BullMQ |
| UI | Tailwind CSS, Radix / shadcn |
| i18n | next-intl (ru / en) |
| Клиентские данные | TanStack Query |
| PWA | Serwist |

Архитектура — **modular monolith**: Anime, Releases и Torrents — отдельные домены с общим auth, уведомлениями и очередями. Подробности для разработки — в [`docs/`](docs/).

---

## Как начать пользоваться

1. Откройте **[anisync.ru](https://anisync.ru)**.
2. Зарегистрируйтесь.
3. В настройках подключите нужные интеграции и включите модули.
4. Добавляйте тайтлы в библиотеку / watchlist — AniSync дальше работает в фоне.

Локальный self-host и клонирование репозитория для пользователей **не предусмотрены**: продукт доступен как сервис.
